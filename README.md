## run it locally

```sh
npm install --include=dev
npm start
```

open [localhost:3000/nehabhatla/](http://localhost:3000/nehabhatla/) to see it. edits show up as you save.

to check the build and tests:

```sh
npm run build
npm test -- --watchAll=false
```
